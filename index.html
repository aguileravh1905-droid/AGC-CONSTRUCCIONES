¿Qué es AGC Construcciones?

Una herramienta diseñada para administrar información relacionada con obras y materiales de construcción.

Gestión sencilla y organizada

AGC Construcciones permite gestionar obras y materiales desde una aplicación de escritorio desarrollada en Python.

El sistema utiliza una base de datos SQLite para almacenar la información de manera local y permitir que los datos permanezcan disponibles al volver a abrir la aplicación.

También cuenta con diferentes niveles de acceso mediante los roles de Administrador y Supervisor.

Funciones principales

  • Registro y administración de obras.
  • Registro y control de materiales.
  • Asignación de materiales a obras.
  • Consulta de información.
  • Control de inventario.
  • Inicio de sesión por usuario y contraseña.
  • Roles de Administrador y Supervisor.

Descargar AGC Construcciones

Sigue los pasos indicados para instalar y comenzar a utilizar el sistema correctamente.

📦 Descarga e instalación

El sistema se encuentra comprimido en un archivo ZIP. Debes descargarlo y extraer su contenido antes de ejecutar la aplicación.

⬇ Descargar AGC Construcciones (.ZIP)
1

Descargar el archivo ZIP

Haz clic en el botón "Descargar AGC Construcciones (.ZIP)" para descargar el archivo comprimido en tu computadora.

2

Extraer el archivo

Una vez descargado el ZIP, haz clic derecho sobre el archivo y selecciona "Extraer todo..." o utiliza la opción disponible en tu computadora.

3

Abrir la carpeta extraída

Entra a la carpeta que se creó después de extraer el archivo ZIP. Dentro encontrarás los archivos necesarios para utilizar AGC Construcciones.

4

Ejecutar AGCConstrucciones.exe

Busca el archivo AGCConstrucciones.exe y haz doble clic sobre él para iniciar el sistema.

5

Crear un acceso directo

Para acceder más fácilmente al programa, puedes crear un acceso directo de AGCConstrucciones.exe en tu escritorio.

6

También puedes fijarlo

Después de abrir el programa, puedes fijarlo a la barra de tareas para tener un acceso rápido cada vez que quieras utilizar AGC Construcciones.

💻 Recomendación para acceder más rápido

Después de extraer el programa, puedes crear un acceso directo en tu escritorio:

  • Haz clic derecho sobre AGCConstrucciones.exe.
  • Selecciona "Enviar a → Escritorio (crear acceso directo)".
  • También puedes fijar el programa a la barra de tareas.

⚠️ Importante: primer inicio del sistema

Como la aplicación se entrega nueva, la primera vez que abras AGC Construcciones será necesario registrar los usuarios iniciales.

Deberás registrar un usuario con el rol de Administrador y un usuario con el rol de Supervisor.

Recuerda muy bien los nombres de usuario y las contraseñas que registres. Si no recuerdas estos datos, no podrás iniciar sesión posteriormente.

ADMINISTRADOR

Usuario Administrador

Durante el primer inicio deberás registrar los datos correspondientes a un usuario Administrador. Este usuario tendrá los permisos administrativos establecidos por el sistema.

SUPERVISOR

Usuario Supervisor

También deberás registrar un usuario Supervisor. Este usuario podrá utilizar las funciones permitidas de acuerdo con su rol.

🔐 Inicios de sesión posteriores

Una vez que hayas registrado tus usuarios, cada vez que cierres AGC Construcciones y vuelvas a abrir el programa, deberás iniciar sesión.

Para ingresar tendrás que utilizar el usuario y la contraseña que registraste anteriormente.

Por seguridad, conserva estos datos en un lugar seguro y evita compartir tus contraseñas.
